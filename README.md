# Sisyphus Boulder Chase 🪨🏃

A visually polished in-browser 3D runner game where the player is chased by a rolling boulder. Built with **Babylon.js** and **Vite**.

![Screenshot](https://via.placeholder.com/800x450?text=Sisyphus+Boulder+Chase)

## 🎮 Controls

- **Left / A**: Move Left
- **Right / D**: Move Right
- **Space / Up / W**: Jump

## 🚀 Getting Started

### Prerequisites

- Node.js installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/zhilyakov1986/sisyphus.git
   cd sisyphus
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

## 🛠️ Tech Stack

- **Engine**: [Babylon.js](https://www.babylonjs.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: TypeScript
